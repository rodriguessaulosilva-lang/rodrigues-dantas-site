# Rodrigues e Dantas Advocacia — Site institucional

Landing page pública do escritório **Rodrigues e Dantas Advocacia**.

- **Domínio:** https://rodriguesedantasadvogados.com.br
- **Stack:** HTML/CSS/JS estático (sem build)
- **Hospedagem:** GitHub Pages (branch `main`, raiz `/`)

## Estrutura
- `index.html` — página única (hero, áreas, equipe, FAQ, contato)
- `CNAME` — domínio custom do GitHub Pages
- `.nojekyll` — serve os arquivos sem processamento Jekyll

## Pendências (trocar quando disponível)
- Fotos reais nas molduras (hero, "O escritório", cards da equipe)
- WhatsApp da Ana Laura (hoje os links de família caem no número do Saulo)
- Logo oficial da marca (hoje há uma marca-texto provisória "RD")

## Como editar
Basta editar `index.html` e dar commit na `main` — o GitHub Pages republica sozinho.
